# Why

## なぜ Self Sunset Protocol を作るのか

私は、不特定多数の一人です。

社会を構成する一人であり、

地球全体を構成する一人でもあります。

Self Sunset Protocol は、

1人の視点から、より良い社会のあり方を考え、試し、学び続けるためのプロジェクトです。


## なぜ義務が鎖に見えるのか

罰則がないのに、圧力だけがある。

勤労と納税の義務には、罰則も強制力もない。
それでも、働いていない人は後ろめたさを感じる。

理由は、義務が強いからではない。
**貢献を示す経路が、一つしかないから**である。

いまの仕組みで「貢献した」と記録されるのは、
賃金労働と納税額だけである。

育児も、介護も、地域の維持も、
記録には残らない。

だから、働いていない人が責められるのではない。
働いていない人が何をしているのかが、誰にも見えない。

見えないものは、無いことにされる。
無いことにされた側は、自分で自分を責める。

罰則のない義務が鎖になるのは、
それが唯一の可視化経路を独占しているときである。

Self Sunset Protocol が扱うのは、義務の撤廃ではない。
**経路を増やすこと**である。



これは、村社会への回帰ではない。

村の共有が成立したのは、善意でも小規模でもなく、
そこから出ていけなかったからである。
監視と排除が、共有の対価だった。

Self Sunset Protocol が試みるのは、
**退出できる状態のまま、相互扶助を成立させること**である。

これは過去に存在したことがない。
だからこれは、復古ではなく、未検証の設計である。
